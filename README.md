# Orean Hotel — Luxury Hospitality Template

An original premium hospitality website created by Orean Software Solutions.

This project is **not a copy of Capella Hotels & Resorts**. It uses original branding, copy, layouts and implementation while studying general luxury-hospitality patterns such as destination discovery, editorial storytelling and reservation UX.

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Included

- Full-screen immersive hero
- Transparent-to-solid sticky navigation
- Full-screen editorial menu
- Slide-in reservation panel
- Signature stay cards
- Seasonal experience feature
- Brand-story and culture sections
- Interactive destination selector
- Recognition/awards presentation
- Responsive mobile layout
- Reduced-motion support
- Scroll reveal motion
- Orean Software Solutions footer credit

## Before using for a real hotel

Replace all sample imagery, hotel names, contact details, awards and copy with verified client content. Connect the booking panel to OreanPlus Booking/PMS or the client's approved reservation provider.
